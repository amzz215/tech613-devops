# What is an operating system 

## What is it? 

OS is an interface between user and the computer hardare. 

- / : Top level directory, AKA root directory
- /root : Home directory for the root user (super user)
- /home : Home directory for other users 
  
---

- /usr : By default softwares are installed in /usr directory (UNIX Sharable Resources)
- /bin : It contains commands used by all users (Binary Files)
- /sbin : It contains commands used by only Super User (root) (Super User Binary Files)
- /var : It is containing variable data like mails, log files
